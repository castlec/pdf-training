# Datasets

No source-derived training samples are published from this repository.

Use `private/datasets/` or `datasets/private/` for local crops, transcriptions,
and manifests. Both locations are ignored by Git.

Only add a public dataset release after documenting that every image and label
is one of:

- created by this project
- generated synthetically from assets we may redistribute
- public domain
- covered by an explicit redistribution license

Possessing or scanning a book is not redistribution permission.
