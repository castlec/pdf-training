# Copyright and Provenance

This repository is intended to be publishable.

## Excluded

- scanned pages and source PDFs
- crops derived from books without redistribution permission
- OCR transcriptions or sample-level reports derived from those pages
- book-specific masks, coordinates, graphs, and renders
- third-party fonts, icons, or reference images without redistribution rights

Keep excluded material in an ignored private directory or in the source-book
workspace.

## Allowed

- code and documentation authored for this project
- empty schemas and templates
- synthetic fixtures made entirely from redistributable assets
- aggregate metrics that do not reproduce source content
- promoted OCR model weights after a memorization/reproduction review

Model cards must state whether training data is distributed and must not expose
private source paths or sample text.

This policy is conservative operational guidance, not a legal determination.
